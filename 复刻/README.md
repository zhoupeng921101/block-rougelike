# 复刻

把 `参考/` 里的作品**按原样重新实现一遍**。

这层的目的是验证「我们真的看懂了它」——研究结论说得通不算数，跑起来一致才算数。
它既不是研究（那是 `参考/`），也不是原创（那是 `新游戏/`）。

```
复刻/
└── Balatro/     Balatro 1.0.1o → web。Phaser 4 + Vite + TS
```

## 先读这条

> **只跑 localhost。不部署、不分发。**
>
> 游戏的**机制与数值**不受版权保护，重新实现是合法的。
> 但**美术、音频、文案**受保护，而这里的工程直接用了 `参考/产物/` 里的原素材
> （`复刻/Balatro/public/assets/`）。一旦做成任何对外可访问的站点，即构成侵权。
>
> 这不是「先这样，以后再说」的权宜之计——它是这层能够存在的前提。
> 想做能公开的东西，那是 `新游戏/` 的事。

## 三层的语义边界

| 层 | 在做什么 | 产出 |
|---|---|---|
| `参考/` | 研究别人的作品 | 分析文档、拆包产物 |
| `复刻/` | 复现别人的作品 | 能跑的代码 |
| `新游戏/` | 造自己的作品 | 设计文档，以后是代码 |

搞混会出事的两个方向：

- **把复刻件的代码搬进 `新游戏/`。** 那是别人的设计，不是你的。
  想借鉴某个机制，走 [借鉴清单.md](../新游戏/借鉴清单.md) 的裁定流程。
- **把研究结论写进复刻工程。** 复刻工程里该有的是「为什么这么写」，
  不是「这个设计好在哪」。后者属于 `参考/结论/`。

## 复刻读什么、不读什么

**读 `参考/产物/<游戏>/源码/` 与 `资源/`**——原始代码与原始素材。

**不读 `参考/产物/<游戏>/配置/配置CSV/`。** 那些 CSV 是脚本从同一批源码派生的
**研究产物**，隔了一层，而且装不下行为：`配置/总表索引.md` 自己标着
`_小丑总表.csv` 的「配置驱动」只有 19/150 = 13%，另外 87% 在源码的分支里。

一句话：**研究查 CSV，复刻读源码。**
