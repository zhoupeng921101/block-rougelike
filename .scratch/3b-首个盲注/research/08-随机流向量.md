# 08 · 随机流口径的原型与测试向量

[种子与随机流的口径](../issues/08-种子与随机流.md) 的附件。原型只用来钉向量，不是落地代码；工程在会话 scratchpad，不在仓库里。

## 怎么跑的

net8.0 控制台工程，`LangVersion 9.0`，用 `<Compile Include … Link>` 链入 block-client 的
`Assets/GameScripts/HotFix/GameLogic/Module/BlockBlast/PortableRng.cs`（只读，没改）。
`dotnet build` 0 错误；同一个 dll 起两个进程各跑一次，输出逐行比对。

- 两个进程除最后一行外逐行一致；
- 最后一行是对照组 `"TESTSEED".GetHashCode()`，两次分别是 `148622727`、`181219200`。

**只跑了 CoreCLR。** Mono / IL2CPP 下一致靠的是论证：派生、取值、洗牌全程 ulong / int 运算，没有浮点，没有靠字典遍历序定先后。没有实测。

## 原型里的四段代码

```csharp
const string Alphabet = "23456789ABCDEFGHJKLMNPQRSTUVWXYZ"; // 32 个，去掉 0 1 I O

static ulong Fnv1a64(string s)
{
    ulong h = 14695981039346656037UL;
    foreach (char c in s)
    {
        if (c > 0x7F) throw new ArgumentException("non-ascii");
        h ^= c;
        h = unchecked(h * 1099511628211UL);
    }
    return h;
}

static XorShift128PlusRng Open(string seed, string key)
    => new XorShift128PlusRng(unchecked((long)Fnv1a64(seed + "/" + key)));

static void Shuffle<T>(IRandomSource rng, IList<T> list)
{
    for (int i = list.Count - 1; i > 0; i--)
    {
        int j = rng.Next(0, i + 1);
        T t = list[i]; list[i] = list[j]; list[j] = t;
    }
}

static string SeedFromEntropy(ulong e)   // 低 40 位，每 5 位一个字符，低位在前
{
    var sb = new StringBuilder(8);
    for (int k = 0; k < 8; k++) { sb.Append(Alphabet[(int)(e & 31)]); e >>= 5; }
    return sb.ToString();
}
```

键用 `purpose + "@" + 段 + "." + 层`，整数用 `ToString(CultureInfo.InvariantCulture)`。

## 测试向量

种子文本 `TESTSEED`，键 `shuffle@1.1`。十六进制都是 16 位小写。

| 项 | 值 |
|---|---|
| `Fnv1a64("")` | `cbf29ce484222325`（FNV-1a 64 标准向量） |
| `Fnv1a64("a")` | `af63dc4c8601ec8c`（FNV-1a 64 标准向量） |
| `Fnv1a64("TESTSEED/shuffle@1.1")` | `0a614c9ad1d15fe0` |
| 开流后的状态 `(s0, s1)` | `3354cb684d657c6f` `08c1e12716cf4049` |
| 开流后 `Next(0,100)` × 8 | `94,88,64,62,65,21,40,21` |
| 另开同一条流，洗 `[0..19]` | `19,13,7,0,4,2,1,15,3,17,11,18,5,12,6,9,10,8,16,14` |
| 洗完后的状态 | `b7c2c3054a65584e` `f370d8348855c47c` |
| 洗完接着 `Next(0,1000)` × 5，原实例与 `XorShift128PlusRng(s0,s1)` 重建实例 | 两边都是 `262,966,377,155,382` |
| `shuffle@1.2` 开流后 `Next(0,100)` × 5 | `19,46,93,24,36` |
| `shuffle@2.1` 开流后 `Next(0,100)` × 5 | `76,6,1,65,93` |
| `SeedFromEntropy(0)` / `(2^40-1)` / `(123456789)` | `22222222` / `ZZZZZZZZ` / `PAMRP522` |

落地时把这张表原样写成 dotnet 单测的常量。常量是另一个进程算出来的，所以这组断言本身就是一项跨进程比对。
