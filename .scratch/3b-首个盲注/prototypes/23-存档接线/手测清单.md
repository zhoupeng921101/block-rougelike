# 23 号票 · Windows 包续玩手测清单

包：`E:\block-rougelike\Demo\Build\Windows\3B.exe`（2026-10-28 14:49 出，含提交 `de292bac`）。
存档目录：`%USERPROFILE%\AppData\LocalLow\block-rougelike\3B\save\`（现在只有一个 `run.json.bad`，是我磁盘测试留下的，可以不管，第 4 条会覆盖它）。

按顺序做，五条接成一局打下去。每条记「过 / 不过 + 看到了什么」。

1. **返回主界面再继续**：双击 3B.exe → 主界面应**没有**「继续」→ 点「开始游戏」→ 落三四块，中间转一次朝向 → 点「返回主界面」→ 主界面出现「继续」→ 点它。
   看：盘面、托盘三块和各自朝向、累计分、方块库剩余、弃置余数，都和离开前一样。
2. **消除演出中途 Alt+F4**：接着打，凑出一次消除；松手后趁「+k」还在逐格跳时按 Alt+F4 → 重开 → 点「继续」。
   看：直接是这一步之后的局面（被消的线已经空了，累计分已经加上），不重播演出。
3. **转朝向后强退**：把托盘里某一块转两三下，记住它最后的朝向 → 等 1 秒以上 → 任务管理器「详细信息」页找到 `3B.exe` → 结束任务 → 重开 → 点「继续」。
   看：那块还是你最后转到的朝向。
4. **改坏 run.json**：接着落两步，**最后一步之后别再转朝向**，记住这时的盘面 → 关掉游戏 → 记事本打开 `save\run.json`，删掉后半截、保存 → 重开 → 点「继续」。
   看：局面比关之前**少一步**（退回上一步）；`save\` 目录里多了（或更新了）`run.json.bad`。
5. **打到胜或负**：接着打，直到结果浮层出现 → 关掉游戏 → 重开。
   看：主界面**没有**「继续」；`save\` 目录里没有 `run.json` 和 `run.json.bak`。

做完第 5 条重开那一次之后就可以关了。写档耗时我从 `Player.log` / `Player-prev.log` 里读，不用你记。
