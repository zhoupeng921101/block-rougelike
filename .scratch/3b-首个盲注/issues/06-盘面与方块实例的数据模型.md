# 06 · 盘面与方块实例的数据模型

Type: wayfinder:grilling
Status: open
Blocked by: 02, 05

## Question

3B 的方块是带身份的实例：形状、点数、强化、版本挂在块上，跟着块走，盲注结束整块洗回。盘面要能回答「这一格属于哪一块」，
而 block-client 的 `BinaryBoard` 只有 64 位占用掩码。规则核心的状态怎么建模？

要裁的：

- **方块实例**：实例 id 怎么发（本局唯一？）；形状、点数、强化与版本的槽；旋转是块的属性还是落子参数。
- **盘面**：占用掩码（判放置、判消行）加「格 → 实例 id」层，要不要再加死格层；一块分几次被消时，块实例什么时候算离场。
- **几个集合**：方块库、抽牌堆、当前一组、弃置堆、已放置，实例在它们之间怎么流转；盲注结束怎么整块洗回。
- **层次**：一局、一盲注、一组、一步，各挂哪些状态。
- **同形态判定**要的「形状种类」和形状 id 的关系（七种骨牌 vs 它们的旋转朝向）。

约束：状态要能序列化（见 [局内存档](09-局内存档的形态与时机.md)）；表现层只读，经事件得知变化。
