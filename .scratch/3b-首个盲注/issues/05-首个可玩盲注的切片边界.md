# 05 · 首个可玩盲注的切片边界

Type: wayfinder:grilling
Status: resolved
Claimed by: slice-boundary

## Question

「打完一个盲注」里具体有什么、什么只留钩子、什么不做？这是下游多张票的根。

以 [3B核心规则.md](../../../新游戏/设计/3B核心规则.md) §2.1–§2.4、§3、§4.4 为全集，起草的边界：

| 项 | 起草 | 备注 |
|---|---|---|
| 8×8 网格、七种四格骨牌、免费旋转 | 做 | |
| 点数（每块一个，计进底分） | 做 | 分布占位，见 [占位数值](11-占位数值.md) |
| 方块库洗回、每组 3 块、放完再发 | 做 | |
| 弃置（一次 1 块、不补、有次数） | 做 | |
| 11 种消除类型的判定与优先级 | 做 | |
| 三乘区计分 | 做 | 无基因时独立倍率恒 ×1，但管线要有这一区 |
| 连击计数 | ? | 基础公式不用它，只有基因用；记不记 |
| 胜负判定（两种失败） | 做 | |
| 强化 4 种、版本 3 种 | 钩子 | 默认库不带；调试入口要不要能塞一块来验证逐格触发 |
| 死格、首领预置块 | ? | 清屏判定提到死格；做成格层还是推迟 |
| 待放置区扩到 5 块 | 钩子 | 数据结构按可变上限写 |
| 拖动时预览消除类型、底分、倍率（§8.5） | ? | 要规则核心能无副作用试算 |
| 进入方式 | ? | 主界面「开始游戏」直进一个占位盲注？ |
| 胜负之后 | ? | 回主界面即可，还是要最小结算页 |
| 局内存档续玩 | 做 | 目的地写明了 |
| 中英文本 | 做 | 属阶段 4 |

每一项的「做 / 钩子 / 不做」都要定，并说清它对数据模型、结算管线的影响。

## Answer

**纵切到「一局只有一个普通盲注」。** 主界面「开始游戏」→ 直接进一个占位盲注 → 打到胜或负 → 战斗界面上叠一层结果浮层 → 回主界面。
中途点「返回主界面」或者直接关窗，重进后主界面会出现「继续」，接着打。

规则核心把 §2.1、§2.2、§2.4 里属于盲注内部的规则和 §3 的计分管线做全；强化、版本、死格、基因段、科技等级只留钩子，在 dotnet 单测里用测试替身验证；局外一切不做。
没有一项会改变目的地或产品形状，全部按授权自裁。依据写在各行和下面的「依据」里，要推翻就改那一行。

### 逐项裁定

| 项 | 裁定 | 对数据模型 | 对结算管线 |
|---|---|---|---|
| 8×8 网格、七种四格骨牌、免费旋转 | **做** | 种类是七值枚举，具体形状由 `GetRotated(基准 id, rot)` 取（[02](02-block-client盘面与手势的可移植面.md)）。旋转是手上这块的状态，落子时作为参数传入；朝向写进存档，续局后看到的朝向不变 | 落子是否合法 = 占用掩码 + 死格掩码（见「死格」行） |
| 点数（每块一个） | **做** | 块实例上一个整数槽；分布用占位（[11](11-占位数值.md)） | 逐格段：每被消 1 格，加一次所属块的点数 |
| 方块库洗回、每组 3 块、放完再发 | **做** | 方块库挂在**局**上。盲注开始时用整库重建抽牌堆并洗匀，「洗回」就是这一步（本图看不到盲注结束后的事）。库里剩的不足一组时，剩几块抽几块（已补进规则 §2.2） | 本图唯一的随机消费点：盲注开始时洗牌，用 [08](08-种子与随机流.md) 的发块流。一组空了才发下一组，发组是一步结束时的收尾动作 |
| 弃置（一次 1 块、不补、有次数） | **做** | 盲注上记剩余次数（占位）；弃掉的块进弃置堆，算花掉的预算 | 弃置是和落子并列的一种「步」：不计分，但要吐事件，也要走发组和胜负判定 |
| 11 种消除类型的判定与优先级 | **做，11 种全做** | 同形态要查「格 → 块实例 → 种类」，所以格 → 实例这一层必须有；清屏看消除之后的占用掩码，死格不在占用掩码里，自然不算方块 | 定类型是纯函数：(满行集合, 满列集合, 被消各格的种类, 消除后的占用) → 类型 |
| 三乘区计分 | **做** | 消除类型的底注和基础倍率按「(类型, 本局等级)」查表，本图等级恒为 1（这就是科技的钩子） | 三区都要有：底分 = 底注 + 被消各格点数之和 + 加算分值（本图为 0）；倍率 = 基础倍率 + 加算倍率（0）；独立倍率 = 各项之积，没有项时是 ×1。数值类型归 [07](07-结算管线与事件流.md) |
| 连击计数 | **做：只记数，不进公式，不上界面** | 盲注上一个整数，进存档 | 一次放置触发了消除，先把连击数加 1 再结算，结算里读到的值含本次；没触发消除的放置把它清零；弃置不改它；盲注开始归零（已补进规则 §2.2） |
| 胜负判定（两种失败） | **做** | 盲注带一个结局：进行中 / 胜 / 负（预算耗尽、放不下两种原因） | 每一步结算完，先判胜再判负。同一次放置既达标又满足失败条件，算胜（已补进规则 §2.4）。「放不下」在落子后、弃置后、发新一组后都要判 |
| 强化 4 种、版本 3 种 | **钩子；不做调试入口** | 块实例上两个枚举槽（无 + 4 种、无 + 3 种），默认库全是「无」，进存档 | 逐格段里每一格留一个「格触发」点，本图没有挂任何效果。触发次数和顺序用单测里注册的测试替身效果来验 |
| 死格 | **钩子：格层和判定都接上，但没有来源** | 盘面多一张死格掩码（恒为 0），进存档 | 落子要避开死格（给 `BinaryBoard` 补一个带 blocked 掩码的重载，见 [02 研究](../research/02-可移植面.md) §1.1）；满线判定里死格算空洞；清屏判定不看死格。单测里直接置死格来验 |
| 首领预置块 | **不做** | 给 [06](06-盘面与方块实例的数据模型.md) 一条约束：预置块是**不属于方块库**的块实例，盲注结束不洗回，所以块实例 id 不能假设「都来自方块库」 | 盲注开始只有「清空网格」，不接预置入口 |
| 待放置区扩到 5 块 | **钩子** | 每组块数是盲注开始时给定的参数（本图 = 3），待放置区是变长列表 | 发组时按这个参数抽 |
| 拖动时预览（§8.5） | **做：高亮会被消的格，显示类型名、该类型本级的底注与基础倍率** | 不额外存东西 | 需要一个无副作用的试算：(局面, 块, 朝向, 落点) → (满行、满列、被消的格、类型)，不碰随机流、不改状态。**不含**被消格点数、强化、基因（已补进规则 §8.5） |
| 进入方式 | **做：主界面只放「开始游戏」「继续」「语言」三个按钮，「开始游戏」直接进占位盲注** | 新局的主种子随机生成（形态归 08），写进存档 | 一局的入口参数 = 主种子 + 默认方块库 + 一个盲注规格（目标分、弃置次数、每组块数） |
| 胜负之后 | **做最小的结果浮层，不做 §8.6 结算页** | 结局一确定就删档 | — |
| 局内存档续玩 | **做** | 全部状态可序列化：方块库与各块实例、抽牌堆顺序、待放置区及各块朝向、盘面三层、弃置余数、连击、累计分、随机流状态 | 什么时候存归 [09](09-局内存档的形态与时机.md)。约束：关窗、强退也要能续，不能只在正常退出时存 |
| 中英文本 | **做** | 规则核心只吐枚举，不碰文本 | — |

### 起草表之外补的几项

| 项 | 裁定 | 理由 |
|---|---|---|
| 基因段 | 钩子：管线里按槽位从左到右遍历一个空列表 | 规则 §3.1 结算顺序的第三段；工程计划阶段 3 要求「给基因和改造留钩子」 |
| 科技（消除类型等级） | 钩子：见「三乘区计分」行，等级恒为 1，没有升级入口 | 同上 |
| 金钱、利息 | 不做，局状态里也不预留字段 | 本图没有任何来源和花处；以后补字段靠存档版本号（09） |
| 分层地图、段、首领、难度、商店、标签 | 不做 | 已在地图的 Out of scope |
| 托盘里放不下的块置灰 | 做 | 这是第二种失败唯一的事前提示；它和「放不下即败」用的是规则核心里同一个查询，几乎没有额外成本 |
| 战斗中「返回主界面」 | 做：一个按钮，PC 上再加 Esc（归 [12](12-PC上的落子与旋转操作.md)） | 不杀进程也能验「中途退出重进」；状态已经按步存好，按钮只负责切界面 |
| 消除表现 | 做最小集：虚影、光带、扫出退场 | 照 [02 研究](../research/02-可移植面.md) §7 列的表现层最小集；震盘、清屏波、粒子碎块往后放 |
| 逐格跳分演出 | 不在本票定，留在迷雾「消除演出的节奏」 | 要等 07 定事件流 |
| 音效、正式美术 | 不做 | 已在 Out of scope |

### 依据（起草表里打问号的几项）

- **连击只记数**：规则 §2.2 定义了连击，§6 的连击叠倍流靠它。记数就是盲注上一个整数，但它属于存档内容：现在不记，到阶段 5 接基因时就得改存档格式。
  不上界面，因为 §8.5 没列它，现在也没有消费方，等基因来了再看。
  弃置不改连击，是照 §2.2 的字面：只有「没消除的放置」清零，而弃置不是放置。弃置本身有次数限制、还花预算，拿它来保连击的代价已经够了。
- **强化不做调试入口**：本图一个强化效果都没有，在游戏里塞一块进去也看不出任何区别。要验的是「每被消 1 格触发一次、按什么顺序」，这是纯逻辑，单测比肉眼准；
  在游戏里显示强化还要美术，不在本图。万态「可填入任意空格」会改落子规则本身，现在钩不出来，只占一个枚举值，见地图的 Out of scope。
- **死格做成钩子，不推迟**：清屏判定（§3.3）和满线判定都写到了死格，而落子判定只差 `BinaryBoard` 的一个重载。现在接上，第一版存档里就有死格掩码；
  推迟的话，盘面结构和存档格式以后都要再动一次。
- **预览要做**：§8.5 写明了要有。11 种类型玩家看不见就学不会，而首个可玩切片要验的正是「瞄着类型放」好不好玩。
  更要紧的是，它逼规则核心从第一天起就能无副作用地试算，后补的话要回头拆管线。
  口径照 Balatro 1.0.1o：选牌时只显示牌型本级的筹码 × 倍率，出牌之后才逐张加分（`参考/产物/Balatro_1.0.1o/源码/cardarea.lua:182`，`update_hand_text` 只传 `G.GAME.hands[text].chips/mult`）。
  这样预览不碰随机流（将来有随机效果的基因不会在拖动时被提前消耗），也不用跑逐格段和基因段。
- **进入方式**：Demo 的主界面现在是空窗，类注释写明界面元素留到局外循环阶段补（`Demo/Assets/GameScripts/HotFix/GameLogic/UI/UIMainMenuPanel.cs:2`）。
  §8.1 列了四个按钮：「选项」「收藏」没有可接的内容，难度选择和地图属阶段 5。「语言」留下，因为它是在包里验英文最省事的入口；只在主界面切，战斗中不用即时刷新，切换机制归 [14](14-文本key表的接法.md)。
  有存档时显示「继续」；点「开始游戏」直接开新局、覆盖旧档，不弹确认。本图一局只有一个盲注，丢档代价很小，确认框随阶段 5 的主界面一起做。
- **胜负之后**：§8.6 要显示的东西（通关奖励、利息、金钱）全在阶段 5，本图没有可显示的。浮层只放：胜利或失败、失败原因（预算耗尽 / 放不下）、累计分与目标分、「返回主界面」。
  结局一确定就删档，所以停在浮层上关窗、重进，不会回到一局已经结束的盲注。

### 补进规则文档的空白

[3B核心规则.md](../../../新游戏/设计/3B核心规则.md) 局部改了三处：

- **§2.2**：方块库剩的不足一组时，剩几块抽几块；连击数含本次，先加 1 再结算，弃置不改它，每个盲注开始时归零。
- **§2.4**：同一次放置既达标又满足失败条件，算胜利；第一种失败改写成「方块库和待放置区都空了」，把最后一块是弃掉而不是放下的情形也收进来。
- **§8.5**：拖动预览显示的是这个消除类型本级的底注与基础倍率，不含被消格的点数、强化、基因。

### 对下游票

- **[06 数据模型](06-盘面与方块实例的数据模型.md)**：方块库挂在局上；块实例要有强化、版本两个枚举槽，种类是可改写的字段；盘面是「占用、格 → 实例、死格」三层；
  连击、弃置余数、每组块数挂在盲注上；预置块是不属于方块库的实例。
- **[07 结算管线](07-结算管线与事件流.md)**：段落顺序是「定类型 → 逐格（点数、格触发点）→ 基因段（空）→ 三区相乘 → 入账 → 先判胜再判负」；
  连击在结算之前更新；预览只跑到定类型为止，必须无副作用、不碰随机流。
- **[09 局内存档](09-局内存档的形态与时机.md)**：要存的内容见「局内存档续玩」一行；结局一确定就删档；主界面看有没有档来决定显不显示「继续」。
- **[10 工程形态](10-规则核心的工程形态与跑局测试.md)**：强化、死格、基因段这几个钩子靠单测里的测试替身来验，测试工程要能往规则核心注册假效果、直接置死格。
- **[11 占位数值](11-占位数值.md)**：要拍的仍是默认方块库、点数、弃置次数、11 种类型的底注与基础倍率、目标分。每组 3 块是规则默认值，不是占位。
- **[12 PC 操作](12-PC上的落子与旋转操作.md)**：多两件——Esc 返回主界面；放不下的块在托盘里置灰。
- **[13 战斗界面线框](13-战斗界面线框.md)**：多两块——结果浮层、「返回主界面」按钮。主界面只有三个按钮，不用出线框。
- **[14 文本 key 表](14-文本key表的接法.md)**：第一批 key 的范围是主界面三个按钮；战斗界面的 11 个类型名、累计分与目标分、方块库剩余、弃置次数、返回主界面；
  结果浮层的胜利、失败和两种失败原因。语言只需在主界面能切。

### 为什么不是别的切法

- **只做规则核心、界面从简**：满足不了目的地（Windows 包里打完一个盲注、能续玩）。
- **顺手做一两种强化（比如铁芯）**：强化的数值和清单都没定（§4.4 只有名字），做出来的效果马上要改；逐格触发点对不对，用测试替身一样能验。
- **把局外入口（难度选择、地图）一起带上**：那是阶段 5，目的地没要。
