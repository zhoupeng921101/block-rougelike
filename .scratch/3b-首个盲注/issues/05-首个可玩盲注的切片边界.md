# 05 · 首个可玩盲注的切片边界

Type: wayfinder:grilling
Status: open

## Question

「打完一个盲注」里具体有什么、什么只留钩子、什么不做？这是下游多张票的根。

以 [3B核心规则.md](../../../新游戏/设计/3B核心规则.md) §2.1–§2.4、§3、§4.4 为全集，起草的边界：

| 项 | 起草 | 备注 |
|---|---|---|
| 8×8 网格、七种四格骨牌、免费旋转 | 做 | |
| 点数（每块一个，计进底分） | 做 | 分布占位，见 [占位数值](11-占位数值.md) |
| 方块库洗回、每组 3 块、放完再发 | 做 | |
| 弃置（一次 1 块、不补、有次数） | 做 | |
| 11 种消除类型的判定与优先级 | 做 | |
| 三乘区计分 | 做 | 无基因时独立倍率恒 ×1，但管线要有这一区 |
| 连击计数 | ? | 基础公式不用它，只有基因用；记不记 |
| 胜负判定（两种失败） | 做 | |
| 强化 4 种、版本 3 种 | 钩子 | 默认库不带；调试入口要不要能塞一块来验证逐格触发 |
| 死格、首领预置块 | ? | 清屏判定提到死格；做成格层还是推迟 |
| 待放置区扩到 5 块 | 钩子 | 数据结构按可变上限写 |
| 拖动时预览消除类型、底分、倍率（§8.5） | ? | 要规则核心能无副作用试算 |
| 进入方式 | ? | 主界面「开始游戏」直进一个占位盲注？ |
| 胜负之后 | ? | 回主界面即可，还是要最小结算页 |
| 局内存档续玩 | 做 | 目的地写明了 |
| 中英文本 | 做 | 属阶段 4 |

每一项的「做 / 钩子 / 不做」都要定，并说清它对数据模型、结算管线的影响。
