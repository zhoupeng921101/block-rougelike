要做：

1. **`PieceGestureFlow`**：新写一个类，骨架用 02 研究 §3.3 列的那几段。`BlockPieceDragger` 拷过来改四处：只认左键、偏移 0、倍率 1.0、PC 阈值 10。另外加一个对外的「取消」入口。
2. **键位表**，集中在一处：右键、R、滚轮下都是顺时针，滚轮上是逆时针，托盘上原地单击也是顺时针；高精度滚轮的累计量满 1 才转一档。
   用旧输入系统轮询，因为 Demo 的 `activeInputHandler` 是 0。
3. **悬停**：记录悬停对象，画托盘槽的悬停态（描边变亮、上浮 6px），它同时是没在拖时的旋转对象。
4. **落点与虚影**：落点解析和吸附共用一个方法；虚影和行列光带的缓存键是 `(col, row, rot)`。拖拽中旋转要立即重算，而且不重建托盘。
5. **预览**：落点可放、而且成线时显示徽章（贴手上那块的上沿），同时高亮类型表里那一行。判线用 20 的 `ResolveClear`，数用类型表查表。
6. **弃置区**：块心在区内时，区高亮并挂出「松手弃置 · 剩余 n → n−1」；次数用完时弹回。
7. **松手**：调规则核心的 `Place` / `Discard`，被拒就弹回；接受后调 28 的全量刷新。本票里还没有演出，盘面直接跳到终态，30 再来接管。
8. **结算锁的开关**：`Lock()` / `Unlock()`。锁着的时候不接受拾起和旋转，Esc 不锁。本票自己不调它，30 接上。
9. **Esc 与失焦**：拖拽中按 Esc 是取消，没在拖时回主界面；窗口失焦、或者丢了抬起事件，都按取消处理。
