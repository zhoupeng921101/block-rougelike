# 13 · 战斗界面线框

Type: wayfinder:prototype
Status: resolved
Claimed by: battle-wireframe
Blocked by: 05, 12

## Question

规则 §8.5 的战斗界面在 1920×1080 下怎么摆：网格；待放置区（3 块，可扩到 5）；弃置区与剩余次数；顶部的关卡信息与方块库剩余；
拖动时的消除类型、底分、倍率；累计分与目标分。草图 `新游戏/设计/图/8.5战斗界面-1.png` 是方向。

做一张粗线框（占位美术，block-client 的方块贴图可以借），定布局与信息层级，作为表现层 task 票的蓝本。
基因栏、道具栏不在本图（见 Out of scope），但线框要给它们留位置。

[切片边界](05-首个可玩盲注的切片边界.md) 加了两块：胜负结果浮层（胜利或失败、失败原因、累计分与目标分、返回主界面）；战斗中的「返回主界面」按钮。主界面只有三个按钮，不出线框。

[PC 操作](12-PC上的落子与旋转操作.md) 加了四条约束：
- 弃置区的命中区不能紧挨托盘，草图里垃圾桶贴着第 5 槽，拖出去容易误弃。
- 弃置区要有三种状态：常态显示剩余次数、块悬在上面时高亮、次数用完时不可用。
- 预览框不能盖住虚影和将被消的行列：要么放在盘外固定的位置，要么贴着手上那块的上沿。
- 托盘里的块要有悬停态和置灰态。

## Answer

**用户选定 A「三栏·草图向」**（2026-10-27，从三套线框里挑的）：照草图摆，左栏常驻 11 种消除类型表，右栏留给基因与道具，托盘在盘下方，弃置区在右下角。
另两项也是用户定的：**点数只标在托盘块上**；**预览徽章贴手上那块的上沿，接受它在竖向消除时压住被消列的一段**。

线框：[prototypes/13-战斗界面线框/index.html](../prototypes/13-战斗界面线框/index.html)，`?variant=A` 是选中的方案。
B「左读数柱」、C「大盘·侧托盘」留作对照；底部切换条能切 6 个场景（静止、拖到盘上、拖到弃置区、弃置用完、胜利、失败）、托盘 3 / 5 块、标注尺寸，按 N 看每套的取舍。

Demo 的 `UIRoot.prefab` 是 Scale With Screen Size、参考 1920×1080、按高匹配（match = 1）。16:10 窗口下设计宽度只剩 1728，所以要按上表的锚点摆：
左栏和返回按钮锚左，方块库、右栏、弃置区锚右，中列居中。这样 16:10 下各区仍不重叠，弃置区到 5 槽托盘的间隔从 245 缩到约 150，还是一个槽宽左右。

### 状态

| 部件 | 状态 |
|---|---|
| 托盘槽 | 常态；悬停：描边变亮、上浮 6px，置灰的块也会亮；置灰（任何朝向都放不下）：块去色、点数变淡，不加文字；空槽：块在手上，画虚线框 |
| 弃置区 | 常态：显示剩余次数。块心悬在区内：区高亮，上沿挂一条「松手弃置 · 剩余 n → n−1」——手上的块会盖住区的中部，次数得挂在外面。次数用完：去色加斜纹、显示 0，拖进来弹回 |
| 预览 | 落点可放、而且至少成 1 条线时才出现：徽章 + 类型表高亮那一行。拖到弃置区上、拖出盘外、松手、取消时一起收起 |
| 点数 | 每块的点数标在托盘槽右下角；落到盘上之后格子不标 |

### 对 [PC 操作](12-PC上的落子与旋转操作.md) 四条约束的落实

- 弃置区与托盘不相邻：5 槽托盘右缘到弃置区 245px（槽宽 150）。
- 弃置区三态、托盘块的悬停态与置灰态：都画了，见上表。
- **预览不盖虚影与将被消的行列：放宽**（用户选择接受遮挡）。徽章贴上沿，横向的虚影和被消的行不会被盖；竖向被消的列，在手上那块正上方的一两格会被压住，被压的信息靠左栏类型表的高亮补。
- 托盘仍在盘下方，12 的吸附口径「向上吸附不吸进最底两行」不用改。

### 不上界面

- 连击（[切片边界](05-首个可玩盲注的切片边界.md)：只记数）。
- 金钱、首领效果：只在盲注信息里留了位置。
