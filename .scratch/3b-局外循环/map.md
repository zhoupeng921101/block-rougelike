## 票

1. **地图模型**（本图第一张）：`RunMap` 生成与 `MapProgress` 推进，纯 C# + 单测。已落地 `RunMap.cs` / `MapProgress.cs` / `RngKeys.Map`。
2. **局外状态**：金钱、难度、地图进度已进 `RunState` 与存档快照（`schema` 仍为 1；盲注可以写 null，商店/选关之间可存；样档已重生成）。库存（消耗品/券）随最小内容集一起加。
3. **经济**：目标分曲线、难度修正、利息与结算，纯函数 + 单测。已落地 `RunEconomy.cs`，`RunState.SettleBlind` 入账并推进地图。
4. **商店**：货架 4 格（基因 72 / 方块 20 / 科技 8，改造的 12 点权重先并进基因）、刷新 $5 起、买基因/方块/科技已落地 `ShopState`；出货与卖出标记进存档，结算后 `OpenShop`、进下一节点自动关店。改造进背包、券与补给包两格待接。
5. **最小内容集**：`MinimalContent` 落了 8 张平推基因、4 张科技、6 张改造、28 块可买方块、11 张有效果的券（只差回收券，等卖价系统）与目录；改造能买进道具栏（2 格），券每段第一场挂一张、买了立即改参数，都能进存档。补给包 5 种已接进商店，开了一半的包能存档。商店货格数 4..6 可变（扩货标签 + 柜台券）。
6. **标签与跳过**：12 个标签全部落地。当场结清的四种（现钱 / 科技 / 改造 / 加块）+ 改下一次商店的四种（折扣 / 扩货 / 急售 / 补给）+ 改下一个盲注的两种（轻敌 / 弃权）+ 蓄息（本段利息封顶 +$20）+ 情报（地图显示首领负面效果）。「下一次」效果存在快照的 `pending` 里，用掉即清。
7. **首领负面效果**：8 个已落地 `Run/RunBosses.cs`。首领在生成地图时按 `map` 流从本段候选里抽一个，存进 `MapNode.BossId` 与 `BlindSpec.BossId`（进档）；高墙 / 碎组 / 断弃在 `SpecForCurrentNode` 折进规格，预置 / 死格 / 紧缩在开盲注时生效（紧缩新增 `blind.removed` 区），增殖在每次发组后补块、偏航每 4 步把盘面整体转 90°。参数全是占位值，集中在该文件顶部。
8. **难度三档**：目标分与运营修正，接进开局。
9. **表现层**：选关屏 `UIMapPanel` 与商店屏 `UIShopPanel` 已落地（节点/货格都是运行时按状态生成），主界面加难度切档，结果浮层加「继续」与通关奖励/利息行；开局不再直接开盲注，进节点才开打。难度选择用一个切档按钮（占位），等美术定稿再做成独立的开局流程。

## 已知的坑

- **存档形状**：`RunSnapshot` 是严格逐成员校验的；加字段要同时改读写、`Validate` 与样档，漏一处单测就红。
- **随机流**：地图只消费 `map` 一条流一次；任何「打开地图屏重掷」的做法都会破坏同种子复现。
- **同种子跑局**：`Sim` 的轨迹比对会因新状态变化；接线后要同步更新四路比对。
- **主工程编辑器关着 Auto Refresh**，看编译结果要手拨 MCP。
- **换屏要「先开新窗、等它开出来、再关旧窗」**：同一帧里先关后开会让 YooAsset 的异步加载永不完成（实测新窗再也不出现，`_pendingMono` 卡住）。`RunFlow.CloseAfterOpen` 就是这条。
- **清本地存档**要用户执行或授权。
