## 第一局（`TESTSEED`，红牌组、白注）

| 对了什么 | 复刻件 |
|---|---|
| 开局 Boss（The Head）、优惠券（Crystal Ball）、小盲 / 大盲标签（Economy / Investment） | 一开始就对 |
| **首手** | **错**：实机 A♥ K♥ Q♦ 9♠ 9♣ 5♣ 5♦ 4♣，复刻件 K♦ Q♥ 10♥ 9♣ 9♠ 5♣ 5♦ 4♣ |
| 三次弃牌补进的 12 张、同花 332 分、兑现 $6 | 修掉首手之后全对 |
| 第一个商店：Raised Fist $5、Pareidolia $5、Buffoon 包、Jumbo Standard 包 | 全对 |
| Jumbo Standard 包的 5 张：9♦、6♠ Bonus、10♥ Steel、J♣、10♠ 紫蜡封 | 全对 |

**首手那个 bug**：5 张对、3 张错位，而且错得有规律——复刻件那三张在「2..9 T J Q K A」里的位置，
恰好是实机那三张在「2..9 A J K Q T」里的位置。`game.lua:2584` 在开局造牌前把 `card_protos`
按 `花色字母..点数字母` 的**字符串**排序，所以 `sort_id`（`pseudoshuffle` 的规范序）是字节序；
复刻件的 `makeStandardDeck` 按 2 → A 造。洗牌本身一直是对的，错的是洗之前那副牌的样子。

标准包那条账（`stdset` → `Enhancedsta` → `frontsta` → `standard_edition` → `stdseal` → `stdsealtype`）
是全局最绕的，第一次实机就对上了。

## 影响

同 seed 的整副牌序全变，所以**所有深度快照都换了一批数**，新旧不可比：

| | 旧牌序 | 新牌序 |
|---|---|---|
| 8 seed 贪心 / 挑牌 | 2.75 / 2.75 | 3.125 / 3.875 |
| 60 seed 贪心 / 挑牌 | 2.383 / 4.1 | 2.3 / 3.85 |

60 seed 上各条结论重新核过，**方向都没变**：存利息、跳盲注、优惠券都不比默认好。
唯一变了措辞的是强化牌那 9 张：从「逐局相同」变成「59 局相同、1 局浅一级」（`S253408`，Steel Joker）。

## 操作上的坑（下一次驱动模拟器前读）

- **档要先走完新手教程。** 没走完时 PLAY 直接开 seed 为 `TUTORIAL` 的局；教程还会强制
  首个商店两格（Joker + The Empress）、优惠券（Grabber）、两个跳过标签，并给补充包加 $3
  （`button_callbacks.lua:1982`、`card.lua:377`）。本机的档已经走完了
- **一次性 `input text` 会吞字乱序**（`TESTSEED` → `TESTDES`），`emu.mjs text` 逐字送
- **`input tap` 太短**，连点时 LÖVE 常只认成悬停；`emu.mjs tap` 用原地按 120ms
- **买东西 / 开包是「长距离慢拖」**：移动版单击商店卡只出提示（`Card:single_tap` 只对手牌区高亮），
  `Card:swipe_up` 在 Lua 里没有调用方（大概在原生层）。实测 `swipe` 从卡上往上拖 ~400px、700ms 能买下并开包
- 移动版手牌区按 `get_nominal` 排，同点数 ♠♥♣♦（`fixtures/card-id.ts` 的 `sortedIds` 照这个排）
- 模拟器里的截图是原作画面，属于受保护素材，**只放 scratchpad，不入库**
