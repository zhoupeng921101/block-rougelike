# 18 · 标签与跳过盲注的切片边界

Label: wayfinder:ticket · decision

## 问题

小丑只剩 Throwback 与 Diet Cola，两张都要**跳过盲注**与**标签**：
Throwback 读 `G.GAME.skips`，Diet Cola 卖掉时 `add_tag(Tag('tag_double'))`。
这是一整套新系统（24 个标签、十种触发时机），而且**它消费 RNG**——
复刻件现在一次都没掷过 `Tag<ante>` 与 `orbital`。

## 裁定

**标签 24 个全部进池、跳过盲注整条流程照抄，效果做到「新档 + 指定 seed」口径下全部可达的那些。**

### 进池但效果不可达（不实现）

`discover_card` 第一句是 `if G.GAME.seeded or G.GAME.challenge then return end`——
**指定 seed 的对局里永远不会「发现」任何东西**。而标签池按 `requires` 过滤：

| 标签 | requires | 新档初值 |
|---|---|---|
| Rare Tag | `j_blueprint` | 未发现 |
| Negative / Foil / Holographic / Polychrome Tag | `e_*` | 未发现 |

所以这 5 个在复刻件里**永远是 `UNAVAILABLE`**（占位、抽中就 `_resample`）。
它们必须留在池里——删掉会改变池子长度、也就改变抽取结果。效果代码不写，真被调到就抛。

### 进池、效果不实现

**Voucher Tag**：它往商店加一张优惠券，而优惠券系统整个不在（16 / 17 号票都推迟了）。
标签照样能拿到，UI 标 `⚠未实现`，与未实现的小丑同一个处理。

### 实现

| 时机 | 标签 |
|---|---|
| `immediate`（拿到就生效） | Top-up / Skip / Garbage / Handy / Economy / Orbital |
| `new_blind_choice`（进盲注选择时） | Boss / Charm / Meteor / Ethereal / Standard / Buffoon |
| `tag_add`（拿到下一个标签时） | Double |
| `round_start_bonus`（下一回合开始） | Juggle |
| `eval`（回合收益） | Investment |
| `store_joker_create`（商店造小丑） | Uncommon |
| `shop_start` / `shop_final_pass` | D6 / Coupon |

## RNG 账

- **`Tag<ante>`**：开局给小盲注、大盲注各抽一个（`game.lua:2396`），
  **打完 Boss、兑现收益时**再抽下一个 Ante 的两个（`button_callbacks.lua:3062`）。
  抽中 `UNAVAILABLE` 就 `Tag<ante>_resample<n>`
- **`orbital`**：每个 Ante 的盲注选择界面**第一次构建时**，对 Small / Big / Boss 各掷一次
  （`UI_definitions.lua:1622`）。**不管标签是不是 Orbital 都掷**——它在界面代码里
- 标签开的包（Charm / Meteor …）走的就是普通的 `Card:open`，账与商店的包相同
- Boss Tag 走 `reroll_boss`，再消费一次 `boss`
- Top-up 造小丑 `create_card('Joker', …, 0, …, 'top')`，Uncommon `create_card(…, 0.9, …, 'uta')`

## 已知的偏差

**Orbital 的候选牌型顺序**来自 `pairs(G.GAME.hands)`——LuaJIT 的哈希遍历序。
复刻件按牌型声明顺序排，**掷点次数对、「掷出的数对应哪个牌型」没法不跑实机核实**。
To Do List 是同一个坑（而且复刻件造它时根本没掷点），一并记进 map。

## 落地顺序

1. 标签数据（生成器）+ 池子 + 抽取 + 跳过盲注流程 + `immediate` / `tag_add` / `eval` /
   `round_start_bonus` 那几个 + **Throwback / Diet Cola → 小丑 150 / 150**
2. 盲注选择与商店那几个：Boss / 五种开包 / Uncommon / D6 / Coupon
3. 表现层：跳过按钮、标签栏
4. bot 学会跳过（贪心不跳、挑牌 bot 看标签值不值）——**这一步才会动墙**
