# 第一个可玩里程碑的切片边界

Type: wayfinder:grilling
Status: open

## Question

全量是 150 小丑 + 22 塔罗 + 幽灵牌 + 优惠券 + 牌组 + 标签 + 28 个 Boss 盲注
+ 20 个挑战 + 补充包 + 强化/版本/蜡封。一次做完不现实。第一个**可玩**的切片切到哪？

切法候选：

- **纵切**：一副基础牌组、完整出牌结算、Ante 1–3、小丑池只放 5 张、商店只卖小丑。
  最快摸到「能玩」，且四条轴都能在小范围内验收一遍。
- **横切**：结算管线做全（含所有强化、版本、蜡封），内容只放一副牌。
  先把最难的正确性问题解决掉。
- 别的切法。

切片边界要**同时**满足四条轴的验收——切出来的东西必须能对拍、能看出外观对不对，
否则里程碑不成立。

**阻塞已解除**——[Lua 到 TS 的翻译策略](03-Lua到TS的翻译策略.md) 裁定走直译，含事件队列。
切片因此不是「先写哪些模块」，而是「先直译哪一段 Lua、哪些小丑分支先接上」。
