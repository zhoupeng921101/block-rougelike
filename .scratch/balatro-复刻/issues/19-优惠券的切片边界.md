# 19 · 优惠券的切片边界

Label: wayfinder:ticket · decision

## 问题

商店的第三排（优惠券格）从 15 号票起一直空着，16 / 17 / 18 号票都把它往后推。
小丑 150 / 150 之后，它是商店里唯一缺的一块，也是 Voucher Tag 唯一不生效的原因。
它消费 RNG（`Voucher<ante>`），而且十几张优惠券改的是整局参数——
商店权重、折扣、版本率、出牌/弃牌次数、手牌上限、利息上限、Ante 本身。

## 裁定

**32 张全部进池，效果做「新档 + 指定 seed」下可达的 16 张一级优惠券。**

### 二级优惠券永远抽不到

`get_current_pool` 对优惠券同样过 `v.unlocked ~= false`（`common_events.lua:2026`），
而 16 张二级优惠券在 `game.lua:610` 起全是 `unlocked = false, start_locked = true`。
它们的解锁走 `check_for_unlock`，**第二句就是 `if G.GAME.seeded then return end`**
（`common_events.lua:1187`）——指定 seed 的对局里局内解锁不可能发生。

所以池子是 32 格、偶数 order 那 16 格恒为 `UNAVAILABLE`（占位不删，理由同小丑与标签）。
**连带不可达的**：Omen Globe、Observatory、Illusion、Retcon、Antimatter 相关的所有分支。

### 实现（16 张）

| 优惠券 | 改什么 | 复刻件落点 |
|---|---|---|
| Overstock | 商店小丑格 +1，**当场补一格** | `Shop.jokerMax` |
| Clearance Sale | `discount_percent = 25`，**全场重新定价** | `setCost(card, discount)` |
| Hone | `edition_rate = 2` | `PoolContext.editionRate` |
| Reroll Surplus | 重掷基价 -2，**这个商店的当前价 max(0, −2)** | `Run.rerollBase` |
| Crystal Ball | 消耗品格 +1 | `consumableSlots` |
| Telescope | 天体包第一张 = 打得最多的牌型的星球（`forced_key`，不掷 soul、不抽池） | `booster-open` |
| Grabber / Wasteful | 每回合出牌 / 弃牌 +1 | `Round` 的 `handsDelta` / `discardsDelta` |
| Tarot / Planet Merchant | `tarot_rate` / `planet_rate` = 9.6 | `PoolContext.rates` |
| Seed Money | 利息上限 50 | `evaluateRound` |
| Blank | 什么也不做 | — |
| Magic Trick | `playing_card_rate = 4`：商店开始卖扑克牌 | `createCardForShop` 的 `Base` 档 |
| Hieroglyph | Ante −1、每回合出牌 −1 | `Run.ante` |
| Director's Cut | 每个 Ante 可花 $10 重掷一次 Boss | `Run.rerollBoss` |
| Paint Brush | 手牌上限 +1 | `handSizeDelta` |

外加 **Voucher Tag**：进商店时每张 Voucher Tag 各加一张优惠券（`Voucher_fromtag`）。

## RNG 账

- **`Voucher<ante>`**：开局抽一次（`game.lua:2395`），**每打完一个 Boss 抽一次**
  （`state_events.lua:284`）。后者在 `ease_ante(1)` 之后——那个事件先入队——所以用的是**新 Ante**。
- 池子剔除三条：已兑换（`used_vouchers`）、`requires` 未满足、**正摆在商店里**（`G.shop_vouchers.cards`）。
  商店关着的时候 `G.shop_vouchers.cards` 是 nil（`CardArea:remove` 置空），这条不起作用。
- Voucher Tag 用 `Voucher_fromtag`——**不带 ante**（原文把拼好 ante 的整串 key 换掉了），跨 Ante 共用一条流；**多张 Voucher Tag 各掷一次**、依次排除已摆出的。
- 空池退化成 `v_blank`。
- Magic Trick 的扑克牌格：`cdt` 权重多一档 4（总和 28 → 32），命中后 `forced_key = 'c_base'`、
  **掷一次 `frontsho<ante>`**，不掷版本（那是 Illusion 的，不可达）。
- Hone 不新增掷点，只改 `poll_edition` 的阈值。
- Director's Cut 重掷 Boss 再消费一次 `boss`。**Boss Tag 也会置 `boss_rerolled`**
  （`button_callbacks.lua:2912`，两条路共用 `reroll_boss`）——拿过 Boss Tag 的 Ante 就不能再用 Director's Cut。

## 容易写错的

- **`redeem` 无条件清 `current_round.voucher`**（`card.lua:1852`），不管买的是不是本 Ante 那张。
  所以买掉 Voucher Tag 给的那张，本 Ante 后面的商店也不再摆主优惠券。
- **Clearance Sale 之后每一次 `set_cost` 都带折扣**，包括新造的卡、改版本、Egg / Gift Card 攒卖价。
  复刻件把 `setCost` 的折扣参数写成**必填**，让编译器替我们找调用点。
  优惠券自己也打折：$10 → `floor(10.5 × 0.75)` = **$7**。
- **Hieroglyph 在商店里就改 Ante**：同一个商店之后的重掷用新 Ante 的 `cdt` key。
  `Shop` 的池子上下文因此改成现取，不能在开张时拍快照。
- **Reroll Surplus 的当前价是另算的**：`current_round.reroll_cost = max(0, cur − 2)`，
  下一次重掷才按 `基价 + 涨幅` 重算。与 D6 Tag 同场时两者不一致，照抄。
- **Crystal Ball / Grabber / Wasteful / Paint Brush 走的是 `round_resets`**，不受 Boss 的 `hands_sub` 影响；
  The Needle 的「砍到只剩 1」按含优惠券的 `round_resets.hands` 算。

## 落地顺序

1. 生成器 + 池子 + 抽取 + 商店优惠券格 + 兑换 + 16 张效果 + Voucher Tag
2. 表现层：优惠券格、兑换按钮、Director's Cut 按钮、已兑换列表
3. 挑牌 bot 学会买优惠券——**这一步才会动墙**

## 交付结果

三步都做了。逻辑层 + 表现层，**863 个测试**（新增 `vouchers.test.ts` 31 条、图集 2 条）。
表现层照旧**没有人眼验收**（无头截图不可用）。

第 3 步的结论是**默认不买**。240 seed：

| 策略 | 均值 | 每局买几张 |
|---|---|---|
| 不买 | **4.025** | 0 |
| 全买，进店先买 | 3.196 | — |
| 精选 10 张，先买（去掉 Hieroglyph） | 3.567（3.638） | — |
| 只买 Grabber / Wasteful / Paint Brush，先买 | 3.929 | — |
| 小丑 ≥ 3 / 4 / 5 张之后才先买精选 | 3.913 / 3.921 / 3.942 | 0.68 / 0.57 / 0.47 |
| 全买，余钱才买 | 4.046（另一批 seed 4.071 对 4.067） | 0.19 |

「余钱才买」打平是因为它几乎买不到——bot 买完小丑和包很少剩 $10。
只要让优惠券抢到钱，就变差。与存利息、跳过盲注同一个结论：bot 的瓶颈是战力，
$10 花在小丑上比花在整局参数上划算，至少对一个只活十来个回合的 bot 是这样。
策略参数留着（`PickyOptions.vouchers`），`depth.slow.test.ts` 钉了两条代表。
