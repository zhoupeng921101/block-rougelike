# 选关屏换图：接入说明

把认可的效果图 v2A（`成品/选关_v2A.png`）落到 Demo 的选关窗 `UIMapPanel`。件全在共用图集 `Atlas_Run` 里（星球、状态环、打勾、面板、按钮、星空底），源在 `美术/共用/切件/`。导入口径见 [工程计划.md](../../工程计划.md)「UI 图导入设置定稿」。

> **2026-10-30 已落地**。实机 1920×1080 截图 `Demo/Assets/Screenshots/map_select.png`，并排对照 `切件/对照_实机vs效果图.jpg`。

## 落地成了什么样

- **整屏**：星空底、顶栏（持有 / 选关 / 段与难度 / 方块库）、左栏消除类型表、右栏背包摘要、中间地图面板（三列表头 小盲 / 大盲 / 首领 + 6 段行 + 行分隔线）、左下「返回主界面」+ Esc。
- **节点**：每段一行、按层分三块，同一层的几个节点在块内均分。节点画成那颗要打的目标星球（60×60，首领 76×76），下面是「轻 $3 / 中 $4 / 重 $5」；可打的套亮青环、打过的套绿环并在右上角打勾、打不了的整颗压暗；首领列没拿到情报时写「首领」，拿到后写首领名。
- **跳过的入口**：能跳的节点（`MapNode.CanSkip`：非首领、第 2 段起）在可打状态下，标签下面多一个「跳过」小钮，点了走 `RunState.SkipNode` → 存档 → 重画本屏。**这是这一屏新开的入口**，之前 UI 上只有「点节点进战斗」。
- **两栏共用**：左栏类型表与右栏背包摘要抽成了 `GameLogic/UI/Common/RunChromeView.cs`，结算屏与选关屏共用一份（原来是各写一遍）。

## 和效果图还差什么

- **悬停卡片**（重 · 目标分 1,890 / 奖励 $5 / 挑战 / 跳过）：没做。现在是「点星球即挑战、跳过在标签下」。
- **打勾**：逻辑做了（`Progress.Visited` 里的节点套绿环 + 勾），但开局截图时还没有走过的节点，所以对照图里没有。要看到得打过一场再回来。
- **首领名**：效果图上直接就写「紧缩盲 / 死格盲」，工程里要拿到情报标签（`RunState.BossIntel`）之后才写，没拿到写「首领」——这是 13 号票定的口径，不是缺件。
- **右栏的科技 / 补给包**：和结算屏一样，工程里没有「科技等级 / 补给包」这个数据，只报基因 / 道具 / 优惠券 / 方块库。
- **星球风格**：工程的星球是 20×20 手绘（3 倍显示），比效果图上模型画的那批更简单；要更接近得按 [工程计划.md](../../工程计划.md)「出图后的像素规整」逐颗出图再替。
- **底栏段/难度**：顶栏写「第 1/6 段 · 标准」，效果图是「第 2/6 段 · 标准难度」——难度名少了「难度」二字（`run_difficulty.standard.name` 的值），要改改文本表那一条。
