# 结算屏换图：接入说明

把认可的效果图 v2A（`成品/结算_v2A.png`）落到 Demo 的结算窗。件已进工程：共用件在 `Atlas_Run`（源 `Assets/AssetRaw/UI/Atlas/Run/`），星空底在 `Assets/AssetRaw/UI/Texture/Run/run_bg.png`。导入口径见 [工程计划.md](../../工程计划.md)「UI 图导入设置定稿」，九宫格边距见各 `切件清单.json`。

## 现在的窗与要改成什么样

- 现在 `UIBattleResultPanel` 是**战斗窗上的小浮层**：一张 660×580 的卡片（`m_rect_Card`），内容只有标题、失败原因、累计分 / 目标分、奖励与利息、「继续」+「返回主界面」。挂 `UILayer.Window`，靠 `m_btn_Mask` 挡点击。
- 效果图是**整屏**：[局外循环.md](../../设计/局外循环.md) §3.2 定的五块——顶栏（持有 / 标题 / 方块库）、左栏消除类型表、结算面板（头像 + 标题 + 累计分 + 最大连击 + 11 种消除分布 + 奖励 / 利息 / 入账 / 持有）、右栏背包（科技 / 补给包 / 方块库 / 优惠券）、底部唯一出口「进入商店」+ Esc。
- 流程不变：赢了照 `RunFlow.AfterResult` 进商店，输了的失败浮层照旧（效果图只画了赢的那一态）。**改的是窗的内容与层**：`UILayer.Window` → `UILayer.UI`，`m_btn_Mask` 与「返回主界面」不再需要（失败态仍要一个出口，见下「没定的事」）。

## 代码要动的

- **整屏化**：`UIBattleResultPanel` 从窗层挪到 `UILayer.UI`，prefab 重搭成整屏；`Data.Anchor`（对准战斗网格中心）与 `_wonSize/_lostSize` 不再需要。
- **补数据**（两样都能在表现层拿到，**不用改规则核心、不动快照**）：
  - **消除类型分布**：`BlindState.TypeCounts`（`IBlindView.TypeCounts`）就是本场 11 种各几次。在 `UIBattlePanel.ShowResult` 进门处、`RunFlow.SettleWon` 把盲注丢掉**之前**读出来，经 `Data` 传进结算窗。
  - **最大连击**：规则核心只留了当前 `Blind.Combo`（`StepPipeline` 里一步没消除就清零），没有「本场最大」。战斗窗收得到每一步的 `StepEnded.Combo`（`RuleEvent`），在窗里顺手记一个最大值即可——纯展示量，不进规则核心、不进存档。读档续打时这个最大值从 0 起算（只影响这一行数字，不影响任何判定）。
  - **利息那句的 `$x`**：`Settlement` 现在只给利息额，句子里要的「结算前持有额」得由 `RunState` 在结算前取一次（或给 `Settlement` 加一个字段——它不落快照）。
- **顶栏**：`$` 是当前持有（结算后），左栏类型表与右栏背包和选关屏是同一套——两块都应抽成共用组件（现在的 `RunInventoryView` 承担右栏，左栏是 `UIMapPanel` 里的 `BuildTypeTable`），三屏共用一份，别各写一遍。

## 没定的事

- **失败态**：效果图只画了赢的那一态。现在失败走同一张浮层、给「返回主界面」。整屏化后失败态要么留浮层（结算窗只做赢的一态），要么也做整屏。建议前者，等这一屏做完再决定。
- **像素中文字体**：效果图里的粗体方块字，Demo 现在是思源黑体 SC Bold。仍按工程计划「像素中文字体还没选」处理。
