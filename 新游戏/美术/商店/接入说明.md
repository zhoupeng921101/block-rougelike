# 商店屏换图：接入说明

把认可的效果图 v2B（`成品/商店_v2B.png`）落到 Demo 的商店窗 `UIShopPanel`。件都在共用图集 `Atlas_Run` 里（面板、按钮、内格、贷架卡片底、图标、星空底）。

> **2026-10-30 已落地**。实机 1920×1080 截图 `Demo/Assets/Screenshots/shop_shelf.png`，并排对照 `切件/对照_实机vs效果图.jpg`。

## 落地成了什么样

- **整屏**：星空底、顶栏（持有 / 商店 / 段与难度 / 方块库）、左栏消除类型表、右栏背包摘要、中间一栏（基因槽 / 道具栏、货架 4 张货卡、优惠券与补给包两张横卡、刷新 / 离开 / Esc）。
- **货卡**：价签、图标、名字、种类、购买按钮；买不起或已售出时按钮变灰、点不动；补给包开着时货架换成包里的候选 + 一个「跳过」。
- **券与补给包**：两张横卡，名字、价格、可点整卡购买。
- 左栏 / 右栏仍走 `RunChromeView`，和结算、选关共用。

## 和效果图还差什么

- **商品说明**：效果图每张货卡下面有一行说明（「每被消 1 格长条块 +1 倍率」）。工程里没有「拿一段说明」的接口——`ItemNames.Offer` 对基因只给名字，改造/券会把说明并进名字里。要照效果图排，得先在 `ItemNames` 上加一个只取说明的方法。
- **价签样式**：效果图是压在卡片上沿的小牌子，这里是卡片内左上角一块格子底。
- **图标**：基因第一批只有四张（激光炮 / 陨石 / 黑洞 / 导弹），按 id 取；改造暂时借「折轨科技」那张天线图，方块借 T 形小骨牌。要一一对上，得按基因/改造清单逐件出 20 格图标。
- **右栏的科技 / 补给包两段**：和前两屏同一条——工程里没有科技等级这个数据。
- **基因 / 道具槽里的图标**：槽位是照 `RunState.Genes` / `Consumables` 现搭的，有东西就填图标；对照图是开局后的空槽。
