1. **先填 [借鉴清单.md](借鉴清单.md)**。12 条取舍来自 [参考/横向对比.md](../参考/横向对比.md) §11，

   第 1、2 条已裁定走 Balatro 的可变乘区，**下一条该定的是第 10 条**——
   它决定时间结构，而时间结构是第 1 条那个裁定能不能成立的前提。
2. 定下来的机制在 `设计/` 开一份文档，把数值口径、边界条件、和参考实现的差异写清楚。
3. 引用参考结论时**带上游戏与版本**，并链到 [参考/结论/](../参考/结论/) 里的对应位置。

## 两条要一直记着

- **Block 不是肉鸽**。它的做法（按个体调难度、按情绪低点触发弹窗、逐关写死胜率）
  服务的是留存与 LTV。搬进肉鸽会直接损伤「这一局是我打出来的」这条核心体验。
  能借的是它的技术骨架（比如实时心流建模），不是它的用途。
  见 [参考/横向对比.md](../参考/横向对比.md) §10。
- **参考结论里的数值有口径**。Brotato 的模拟 DPS 与最优套装是特定假设下的推导，
  Block 的包内数值只是客户端默认分支。照搬数字之前先读该条结论的前提。
