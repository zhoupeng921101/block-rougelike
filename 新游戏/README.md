## 起点文档里待解决的问题

转写时读出来的，**只是列出来，都还没裁定**：

1. **方块有两套分类在混用。** §2.1 按几何形状分（单格、长条、L、田、S/Z、直线），
   清单里又有借自花色的四种形态（圆核、尖棱、三叶、田字）和借自人头牌的「冠饰块」。
   其中「L 拐角块」同时被当成冠饰块、三叶块、人头牌、J/K/Q 来用。
2. **借自扑克的概念在方块里没有定义。** 包括：
   - 序数：9 号块、序数 6、序数 2–5、斐波那契数
   - 弃置次数：§2.2 的流程里没有弃置，但 8.5 的界面里有删除
   - 储备库 52 枚、手牌上限
   - 「回合」「放置回合」「盲注」三者的关系
3. **消除类型的口径不一致。** §3.3 列了 1 条、多线、十字、清屏四种；科技表有 12 种，
   多出同形态、拐角双线、五线、同形态十字等。另外 N 还没定，而整行消除在 N×N 网格里恒为 N 格，
   所以「≥5 格连续直线」指什么要先说清楚。
4. **「每个强效果绑定代价」（§1.3）落到清单上有三种写法**：本盲注目标分 +X%、机会成本、真实负面。
   不少条目写的是「无直接负面」。哪种算数还没定。
5. §5.2 标题是「好用优先抽取」，正文却是「纯随机」。
6. §6 最后一行「小丑牌留」疑似笔误，四列内容也和其他行对不上。
7. **第 8 章的编号和内容都不全。**
   - 有两个「8.2 主界面」，第二个实为星系与关卡选择。
   - 缺 8.4；有两个 8.7。
   - 8.6 正文只有「如图」；商店和章节结算只有图。
8. **内容量。** 150 个基因逐条对应小丑。Balatro 的小丑只有 19/150 是配置驱动，
   其余是按名字写死的分支，见[总表索引.md](../参考/产物/Balatro_1.0.1o/配置/总表索引.md)。
   照这个比例，每个基因的工作量要按「一段代码」估，不是「一行配置」。

## 一直要记着

- **Block 不是肉鸽**。它按个体调难度、在情绪低点触发弹窗、逐关写死胜率，服务的是留存与 LTV。
  战斗层借它的放块消行没问题；要借这几种做法的话，先说明目标差异与适用条件。
  见 [参考/横向对比.md](../参考/横向对比.md) §10。
- **参考结论里的数值有口径**。Block 的包内数值只是客户端默认分支，照搬数字之前先读该条结论的前提。
