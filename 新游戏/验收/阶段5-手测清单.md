# 阶段 5 真实输入手测清单

对象：编辑器 Play 或 Windows 包（`3B/出 Windows 包`）。脚本驱动验过的部分见 [阶段5-端到端.md](阶段5-端到端.md)，
这份只列**必须用真鼠标/键盘**才能确认的部分。每条后面留「结果」栏，跑完把异常处填上。

## A. 主界面

| # | 步骤 | 期望 | 结果 |
|---|---|---|---|
| A1 | 首次启动（无档） | 只有「开始游戏 / 收藏 / 选项 / 语言」，没有「继续」 | |
| A2 | 点「开始游戏」 | 进难度选择页：三档各带一句说明，默认停在上次选的那档；点一档高亮，「开始」开局，「返回」回主界面且「继续」还在 | |
| A3 | 「选项」里点「声音」两次 | 开 → 关 → 开；关着时按钮、落子、背景音乐都不响；重启游戏仍是关 | |
| A3b | 点「收藏」 | 三栏列出基因（稀有度、价）、补给包、科技、强化与版本、改造、优惠券；切语言整页跟着换 | |
| A4 | 点「语言」 | 界面中英切换，静态文案与动态数字都换语言，不重开窗 | |
| A5 | 开局后退出到主界面再回 | 「继续」出现，点它回到上次那一屏 | |

## B. 选关

| # | 步骤 | 期望 | 结果 |
|---|---|---|---|
| B1 | 开局 | 6 段 × 3 层；第 1 段第 1 层只有一个节点，且不能跳 | |
| B2 | 跳过一个节点（第 2 段起） | 节点变灰、不进商店、标签生效（钱/商店折扣/下个盲注等） | |
| B3 | 首领节点 | 拿到「情报」标签前只显示「首领」，之后显示具体负面效果 | |
| B4 | 点首领节点 | 战斗里能看到这一场的负面效果（如预置块、死格、盘面每 4 步旋转） | |

## C. 战斗（手感与演出）

| # | 步骤 | 期望 | 结果 |
|---|---|---|---|
| C1 | 拖一块落子 | 跟手、有虚影与消行预览；松手后落子、计数框弹「+k」 | |
| C2 | 左键点托盘里的块 / 滚轮 | 转朝向，有旋转音与动画 | |
| C3 | 三次弃置用完后再拖进弃置区 | 块弹回，弃置区显示「弃置已用完」 | |
| C4 | 一次四行以上的消除 | 逐拍音逐拍升调、消行冲击、评价语音与评价字同刻、清屏音与光束都对得上 | |
| C5 | 打到放不下 | 先响一声「放不下」再弹失败浮层 | |
| C6 | Esc（拖拽中 / 不拖时） | 拖拽中取消这一手；不拖时回主界面 | |

## D. 结算与商店

| # | 步骤 | 期望 | 结果 |
|---|---|---|---|
| D1 | 打赢一场 | 浮层显示「累计分 / 目标分」与「通关奖励 · 利息」；「继续」进商店，「返回主界面」放弃 | |
| D2 | 商店买货 | 扣钱、货格变灰；槽位满时买不了（基因/改造） | |
| D3 | 刷新 | 扣刷新费、货格换一批、价格随次数上涨（急售标签时免费且不涨价） | |
| D4 | 买补给包 | 扣钱后在同一块地方出现候选，选够次数回货架 | |
| D5 | 买券 | 立刻生效（扩槽/加组/利息封顶/货格等），存读档后仍在 | |
| D6 | 离开商店 | 回选关屏，下一层节点可点 | |
| D7 | 商店右栏 | 基因 ◀ ▶ 换位、卖（入账 = 基础价一半）；道具「使用」；改块的改造弹出方块库让你挑一块 | |
| D8 | 开了包不想要 | 「跳过」关包，回货架 | |
| D9 | 没打出过某种消除 | 货架与科技包里没有对应科技；打出过之后才出现 | |

## G. 构筑（核心规则 §3–§5 补齐）

| # | 步骤 | 期望 | 结果 |
|---|---|---|---|
| G1 | 战斗里把一张基因拖到另一格 | 两格换位，之后的消除按新顺序结算（+倍率在左、×倍率在右分更高） | |
| G2 | 战斗里点一下基因或道具 | 那一格底部出「卖 $x」（道具不用目标的还有「使用」），再点一下收起 | |
| G3 | 把琉璃 / 铁芯 / 金箔 / 万态改造拖到托盘块或盘上的块 | 块换色；之后消掉它：琉璃 ×倍率、可能碎掉，铁芯 +倍率，金箔给钱，万态让混形的线算同形态 | |
| G4 | 把垂湮改造拖到托盘里最后一块 | 块消失、方块库少一块，托盘空了就补发一组 | |
| G5 | 镀金改造拖到基因格 | 1/4 概率基因名后出现版本；有版本的基因再拖上去不让用 | |
| G6 | 买到带「负片」的基因 | 基因栏占槽数不变，满槽时也买得进 | |
| G7 | 买纯形基因（G015）后进下一关 | 那一场目标分比平时高 25%，再下一场恢复 | |
| G8 | 选关屏左栏 | 11 种消除类型的等级、底注×倍率、打出过几次；用了科技之后等级与底注跟着涨 | |

## 已知的取舍（不算缺陷）

- 首版没有音量滑条与混音调校；选项页只有声音开关与语言。
- 主界面的子页（难度、选项、收藏）、背包栏、类型表都是运行时拼的占位界面，等美术定稿再做成预制体。
- 音效全部是动物乐园的占位素材，阶段 6 换。
