## _区域总表（3 条）

- 主键：id
- 原始数据：`资源/zones/zone_*/zone_*_data.tres`
- 逻辑出处：`源码/zones/zone_service.gd`
- 全部列：`id` / `中文名` / `英文名` / `宽` / `高` / `默认解锁` / `波次数` / `出处`
