## 通用列

每张表都有这几列，含义一致：

| 列 | 说明 |
|---|---|
| `key` | 资产键，与 `配置JSON/` 和 `图片资源/` 对得上 |
| `中文名` / `英文名` | 取自 `文本/zh_CN.json`、`en-us.json` |
| `中文描述` / `英文描述` | **占位符已填成实际数值**，富文本标记已剥 |
| `数值参数` | 原型表 `config` 拍平成 `k=v` |
| `占位变量取值` | `#1#` `#2#` 各取自哪个字段、值是多少 |
| `order` | 游戏内排序 |
| `图片` | 对应 `图片资源/` 下的 PNG 相对路径 |

> 成长型条目（小丑里有 43 张）描述里填的是**初始值**，实际强度要按「触发次数 × 增量」估。
