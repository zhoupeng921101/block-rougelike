# block-rougelike

做一款肉鸽游戏，参考《Balatro》《Brotato》《Block》三款已拆包的成品。

```
新游戏/          ← 目标：自研游戏的设计与实现
复刻/            ← 练手：把参考作品按原样重新实现一遍
参考/            ← 手段：三款游戏的拆包资料与研究结论
  结论/          ← 12 篇设计分析（日常读这层）
  产物/          ← 拆包原件：配置表、源码、资源（要证据时下钻）
源包/            ← APK 原件，不入库
```

三层的分工：**`参考/` 是研究已有成品，`复刻/` 是重新实现它们，`新游戏/` 是原创。**
搞混会出事——比如把复刻件的代码当成新游戏的资产，或者把研究结论写进复刻工程。

> **`复刻/` 里的东西只跑 localhost，不部署、不分发。**
> 游戏的机制与数值不受版权保护，重新实现是合法的；但美术、音频、文案受保护，
> 而复刻工程直接用了 `参考/产物/` 里的原素材。详见 [复刻/README.md](复刻/README.md)。

三款的定位不一样：**Balatro 与 Brotato 是肉鸽标杆，Block 不是肉鸽**——
它是商业化调优与 A/B 实验的对照组，目标是留存与 LTV，
收录它是为了照出前两款默认成立、自己却不自知的那些前提。
